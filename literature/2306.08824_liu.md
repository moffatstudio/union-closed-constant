## 0. Headline result

Frankl's union-closed sets conjecture: some element of a union-closed family lies in ≥ 1/2 of the sets.
Liu's paper claims, **conditional on two numerically-verified (not proven) hypotheses**, that some element
lies in ≥ c′ · |F| sets with

    c′ ≈ 0.382709087918741                                   (93)

improving the prior record c* ≈ 0.3823455 (Sawin's coupling class, evaluated by Yu/Cambie), which itself
improved Gilmer's original constant (3−√5)/2 ≈ 0.381966.

## 1. Background recap (Section I), as stated in the paper

Binary entropy: h(s) := s·log₂(1/s) + s̄·log₂(1/s̄), s̄ := 1−s.

**Proposition 1** (Gilmer/Chase–Lovett/Alweiss–Huang–Sellke/Sawin, sharp form). If S ∈ [0,1] has E[S]=u and
T is an i.i.d. copy of S, then

    E[h(S̄T̄)] ≥ E[h(S)] · { h(2u−u²)/h(u)         if u ≤ (3−√5)/2
                             (1−u)^{2/(√5−1)}      if u ≥ (3−√5)/2 }                    (1)

Gilmer's entropy argument: with Xⁿ, Yⁿ i.i.d. binary vectors, PXn equiprobable on a union-closed family,

    H(Xⁿ∨Yⁿ) = Σᵢ H(Xᵢ∨Yᵢ | Xⁱ⁻¹∨Yⁱ⁻¹) ≥ Σᵢ H(Xᵢ∨Yᵢ | Xⁱ⁻¹,Yⁱ⁻¹)                        (2)-(3)
    H(Xⁿ) = Σᵢ H(Xᵢ | Xⁱ⁻¹,Yⁱ⁻¹)                                                        (4)-(5)

If E[Xᵢ] < (3−√5)/2 for all i, Proposition 1 applied to S:=E[Xᵢ|Xⁱ⁻¹], T:=E[Yᵢ|Yⁱ⁻¹] gives H(Xⁿ∨Yⁿ) >
H(Xⁿ), contradicting equiprobability maximizing entropy on a fixed support ⇒ the family cannot be
union-closed ⇒ some element is in ≥ (3−√5)/2 fraction of sets.

**Sawin's improvement / Proposition 2** (evaluated numerically by Yu arXiv:2212.00658 and Cambie
arXiv:2212.12500): there exist analytically-defined c*, α* such that for c < c*, some C>1 exists with

    ᾱ*E[h(S̄T̄)] + α*E[h(S∨R∨min(S+R,1/2))] ≥ C·E[h(S)]                                  (6)

whenever PSR is symmetric, PST=PS⊗PT, PS=PT, E[S]≤c. (h(S∨R∨min(S+R,1/2)) is the maximum possible
H(Xᵢ∨Yᵢ|Xⁱ⁻¹,Yⁱ⁻¹) for given marginals S,T — the "max-entropy coupling".) Optimizer (via Krein–Milman
reduction to 5 dims by Yu, further cardinality reduction by Cambie):

    PSR(1,b)=PSR(b,1)=a;  PSR(b,b)=1−2a                                                  (7)-(8)
    (1−2a)h(1/2) = (1−a)h(b)                                                             (9)
    (1−a)²h(b̄²) = (1−a)h(b)                                                              (10)

⟹ h(b)(2−h(b)) = h(b̄²), which has two roots in (0,1); take the larger root
b* ≈ 0.329454738503037, with a* ≈ 0.0788772927059232. These give

    c* ≈ 0.3823455                                                                       (11)

Define fα(a,b) := ᾱE[h(S̄T̄)] + αE[h(S∨R∨min(S+R,1/2))] − E[h(S)]. Stationarity conditions
∂a·da+∂b·db=0 with dE[S]=b̄·da+ā·db=0 give a closed form for α* (eq. 15); plugging in a*,b* gives
**α* ≈ 0.0356069**.

## 2. Contribution of this paper

A new coupling class ("conditionally IID") strictly beats c* (Theorem 6, non-numerical/analytic proof of
strict improvement), and a numerically-optimized instance of it gives the explicit improved constant
c′ ≈ 0.382709 (Theorem 13, conditional on numerically-verified hypotheses).

## 3. Protocols and the conditionally-IID coupling (Section II)

**Definition 1 (protocol).** Π is a protocol if for every (s,t)∈[0,1]², Π_{s,t} is a distribution on
{0,1}² with E[X]=s, E[Y]=t for (X,Y)~Π_{s,t}. Given PXn, a protocol generates Xⁿ,Yⁿ sequentially: at step
i, given (Xⁱ⁻¹,Yⁱ⁻¹), draw (Xᵢ,Yᵢ)~Π_{s,t} with s:=P(Xᵢ=1|Xⁱ⁻¹), t:=P(Yᵢ=1|Yⁱ⁻¹). This class includes
Gilmer's i.i.d. coupling, Sawin's max-entropy coupling, Yu's maximal-correlation coupling, and the new
conditionally-i.i.d. coupling below.

**General multi-protocol inequality.** For protocols Π^(1),...,Π^(K), weights w_k≥0 summing to 1, C>1, and
Cₖ(µ) a set of couplings of µ,µ "large enough to contain all couplings induced by protocol k":

    Σ_k w_k · inf_{PST∈Ck(µ)} E[h(Π^(k)_{S,T}(0,0))] ≥ C·E[h(S)]        for all µ with mean ≤ c        (16)

**Proposition 3.** If (16) holds with constant c>0, then c is a valid lower bound for the union-closed sets
conjecture constant. (Proof: same entropy argument as (2)-(5), applied to K protocols simultaneously and
summed with weights w_k, using equiprobable-maximizes-entropy again.)

Gilmer's case: K=1, Π^(1)_{s,t}=Bern(s)×Bern(t), C1={µ×µ} (singleton). Sawin's case: K=2, Π^(2) is the
greedy max-entropy-of-OR coupling, C2(µ) = essentially all symmetric couplings of µ,µ. Yu's case: Π_{s,t}
has maximal-correlation ≤ ρ; by tensorization C(µ) = distributions with the same maximal-correlation bound.

**Definition 2 (conditionally IID protocol).** Π is conditionally IID if

    Π_{s,t}(x,y) = ∫ Q_{u,s}(x) Q_{u,t}(y) P_U(du)                                       (18)

where Q_{u,s} is Bernoulli with mean a function of (u,s), and P_U is (WLOG, by the isomorphism theorem for
standard probability spaces) uniform on [0,1]. Equivalently: there is an auxiliary variable U (extended
sequence Uⁱ) such that Xᵢ and Yᵢ are conditionally i.i.d. given Uⁱ, and each Xᵢ is simulated from
(Xⁱ⁻¹,Uⁱ⁻¹) alone (not referencing the Y-sequence), symmetrically for Yᵢ. This is the "coupling" that gives
the paper its name.

*Non-example*: Sawin's max-entropy protocol Π^(2)_{s,t}(0,0)=1−s∨t∨min(s+t,1/2) is **not** conditionally
IID — for s=t<1/4 the matrix [Π^(2)_{s,t}(x,y)]_{x,y} has diagonal (0, 1−2s) and off-diagonal s, which is
not PSD, so it cannot be written as (18).

**Example 4** (illustrative, not the one used numerically). U uniform on [0,1], a(·) measurable on [0,1].
Given U=u, s: draw B~Ber(a(s)) using X's local randomness; if B=0, X~Ber(s) locally; if B=1, X=1_{U<s}.
Then X~Ber(s) marginally, and symmetrically for Y using t. Then

    P[X=Y=0|U] = a(s)a(t)1_{U≥s∨t} + a(s)(1−a(t))1_{U≥s·t̄} + (1−a(s))a(t)·s̄·1_{U≥t} + (1−a(s))(1−a(t))s̄t̄  (19)

    Π_{s,t}(0,0) = a(s)a(t)(1−s∨t) + (1−a(s))a(t)s̄t̄ + a(s)(1−a(t))s̄t̄ + (1−a(s))(1−a(t))s̄t̄            (20)
                 = s̄t̄ + a(s)a(t)(s̄∧t̄ − s̄t̄)                                                            (21)

Choosing a(·) to maximize h(Π_{s,t}(0,0)) for fixed t gives a piecewise closed form (eq. 22, entropy-optimal
a(t), not used further).

**Example 5** (the one actually used numerically in Section V). P_U uniform on [0,1]; f(·) measurable with
0 ≤ f(s̄) ≤ s∧s̄. Given u,s: set X=0 with probability s̄ + f(s̄)·(1_{u>1/2} − 1_{u≤1/2}), X=1 otherwise
(symmetrically for Y, using the *same* u). Then

    Π_{s,t}(0,0) = s̄t̄ + f(s̄)f(t̄)

The coupling class used for the finite-dim optimization (Section IV-V) restricts to Example 5:

    C3(µ) := {couplings of µ,µ} ∩ cl·conv{symmetric rank-1 measures}                                    (23)

(closure in weak convergence, enabling Krein–Milman later). Intuition: since Xᵢ,Yᵢ are conditionally i.i.d.
given Uⁱ, the pair (E[Xᵢ|Xⁱ⁻¹], E[Yᵢ|Yⁱ⁻¹]) is conditionally i.i.d. given a mixing variable — hence PST
lies in the closed convex hull of "symmetric rank-1" (i.e. i.i.d.-product) measures, i.e. is a **mixture of
i.i.d. distributions**. This is the entire point of the "conditionally IID" name.

## 4. Analytic proof of strict improvement (Section III)

**Theorem 6.** The union-closed sets conjecture holds with a constant strictly larger than c* ≈ 0.3823455.

Proof strategy: perturb Sawin/Yu/Cambie's optimal scheme with a small weight β on a conditionally-IID
protocol (specifically the Example-4 protocol with the entropy-optimal a(t) of eq. 22).

**Lemma 7** (degenerate/point-mass case is not a problem). For c∈(0,1), if µₙ is a sequence of probability
measures with mean c converging weakly to µ* (the point mass giving mean c, i.e. Bernoulli(c)), then

    liminf_n [∫h(s̄t̄)µₙ(ds)µₙ(dt)] / [∫h(s)µₙ(ds)] ≥ 2c̄                                                (24)

(Proof sketch: split the domain into a shrinking neighborhood Aₙ=[0,εₙ) of 0 and its complement Bₙ, using
h(x)~x·ln(1/x) as x→0 and applying Proposition 1 on the conditional measure restricted to Aₙ.)

**Lemma 8** (the actual strict-improvement statement). Let a(·) be as in (22), Π^(3) the corresponding
conditionally-i.i.d. protocol (built from Example 4). There exist β∈(0,1), c′>c*, C>1 such that

    ᾱ*β̄E[h(S̄T̄)] + α*β̄E[h(S∨R1∨min(S+R1,1/2))] + β·E[h(S̄R̄2 + a(S)a(R2)(S̄∧R̄2 − S̄R̄2))] ≥ C·E[h(S)]    (29)

whenever E[S]≤c′, PST∈C1(PS), PSR1∈C2(PS), PSR2∈C3(PS).

Proof idea (this is qualitative/existence, not a numeric evaluation of c′): let P*_S be the two-point
optimal distribution from (7)-(8)/(11) (mass 1−a* at b*, mass a* at 1). One shows
inf_{PSR2∈C3(P*_S)} E[h(Π^(3)_{S,R2}(0,0))]/E[h(S)] > 1 — strictly bigger than the value 1 attained at the
same infimum taken over the *larger* set C2(P*_S) (Sawin's class), because the minimizer of the C2-problem,
namely P*_{SR2}(1,1)=0, P*_{SR2}(b*,1)=P*_{SR2}(1,b*)=a*, P*_{SR2}(b*,b*)=1−2a*, is **not** positive
semidefinite as a matrix on {b*,1}² and hence lies in C2 but not C3. A continuity/Wasserstein-perturbation
argument (there's a δ>0 neighborhood of P*_S where the same strict inequality holds) plus a compactness
argument over the rest of the mean-≤c* region (using Lemma 7 to handle the point-mass boundary case) shows
a strictly positive gap Cδ>1 exists uniformly; then β is chosen small enough that β̄·Cδ>1, and a final
"push the mean constraint slightly past c*" limiting argument (again invoking Lemma 7 at the boundary)
extends validity to some c′>c*. **No explicit value of c′ or β is given in Section III** — this section
establishes strict improvement exists, not how large it is. The quantitative bound (0.382709) comes only
from the separate numerical Section V construction (Example 5 + the 9-dim optimization), not from this
existence argument.

**Remark 1** (checked and ruled out: Yu's maximal-correlation class does not help). Yu's coupling: Π_{s,t}
has maximal correlation ≤ ρ for all (s,t); by tensorization C(µ) = distributions on [0,1]² with maximal
correlation ≤ ρ bounded the same way. The question: can some ρ∈(0,1) give a Lemma-8-style strict
improvement via a small-weight perturbation? Answer: **no**. The condition required would be

    PST(b*,b*)·h(Π_{b*b*}(0,0)) − (1−a*)h(b*) > 0                                                        (42)

where PST is the mean-preserving coupling of PS=P*_S with maximal correlation ≤ ρ minimizing PST(b*,b*),
and Π_{b*b*} is the maximal-correlation-≤ρ coupling of two Bernoulli(b*) maximizing h(Π_{b*b*}(0,0)). Using
closed forms (maximal correlation = 2nd singular value of a matrix): Π_{b*b*}(0,0)=min{b̄*²+b*b̄*ρ, 0.5} and
PST(b*,b*)=max{ā*²−a*ā*ρ, 1−2ā*} [from Yu's paper]. Liu states: "we can verify that the left side of (42)
is, in fact, negative for all ρ∈(0,1)" — i.e. Yu's class, perturbed this way, gives **no improvement**
over c*. This is an explicit statement that a natural, more general-looking coupling class does *not*
extend the bound (at least not via this small-perturbation technique) — the conditionally-IID class was
specifically chosen because it does work.

## 5. Cardinality reduction (Section IV)

Goal: strip out the (expensive/hard to handle numerically) Sawin max-entropy term from (29), leaving just a
mixture of Gilmer's i.i.d. term and the conditionally-IID term, then show the optimization over PSR2 can be
restricted to finitely-supported distributions. Working problem (drops the middle term of (29), α* term):

    inf_{PSR2∈C3, E[S]≤c}  [ β̄·E[h(S̄T̄)] + β·E[h(Π_{S,R2}(0,0))] − E[h(S)] ]                             (43)

with S,T i.i.d., c>0 a free parameter (this is the quantity numerically evaluated in Section V, not (29)).

**Theorem 9.** For any conditionally-IID protocol Π (Definition 2), the infimum in (43) is attained by some
PSR2 that is a **mixture of exactly two i.i.d. distributions**:

    PSR2(s,r) = E[ PS|W(s|W) · PS|W(r|W) ]                                                               (44)

for some *binary* random variable W. Proof: existence of a minimizer via Prokhorov's theorem (weak
compactness); E[h(S̄T̄)] is concave on C3∩{mean=c′} (cited to [AHS22]/Alweiss–Huang–Sellke) and the other
two terms of (43) are linear in PSR2, so the infimum is at an extreme point of C3∩{mean=c′}, by
Krein–Milman. Any element of C3 is representable as (44) for some (possibly non-binary, possibly
infinite-support) W by definition of C3 as a closed convex hull of rank-1 (i.i.d.) measures; the extreme
points of {distributions of E[S|W] on ℝ with fixed mean c′} are exactly two-point (binary) mixtures, so the
extreme points of C3∩{mean=c′} correspond to binary W, i.e. exactly two i.i.d. components.

⟹ It suffices to write PSR2(s,r) = q·P1(s)P1(r) + q̄·P0(s)P0(r) for some q∈[0,1] and probability measures
P0,P1 on [0,1]. (45)

**Lemma 10** (spectral-norm growth bound for polynomial-generated matrices, technical tool). Given
polynomials p(·), p1(·,·), let Bₖ be the matrix whose (i,j) entry is the coefficient of xⁱyʲ in
p1(x,y)pᵏ(x)pᵏ(y). Then ‖Bₖ‖_op ≤ Cᵏ for some C>0 independent of k. (Proof: for p1≡1, Bₖ is rank-1
symmetric and ‖Bₖ‖²_op = Σₘ(a_m^{(k)})² which, by a large-deviation/type-counting argument, is
exp(2k·sup_{PM}{E[log(a_M)]+H(PM)} + o(k)) — exponential in k; general p1 follows by subadditivity.)

**Lemma 11** (concavity for a specific perturbed family). Fix a polynomial p(·) with p(1)=0, and let Π be
the Example-5 protocol with f(x)=l·x·p(x) for small l>0. Then for any c,d∈[0,1], the functional
µ ↦ ∫h(Π_{s,r}(0,0))µ(ds)µ(dr), restricted to probability measures µ with E_µ[S]=c and E_µ[f(S̄)]=d, is
**concave**. Proof (a substantial second-order/integration-by-parts computation, mirroring [AHS22]'s
proof for the pure-i.i.d. case): write x:=s̄, y:=t̄, I:=Π_{s,r}(0,0)=xy+f(x)f(y). Need
−∫h(I)µ(dx)µ(dy) ≥ 0 for µ with ∫dµ=0, ∫xµ(dx)=0, ∫f(x)µ(dx)=0 (the "second variation" constraint set).
Integrating by parts twice (γ(x):=µ([0,x])):

    −∫h(I)µ(dx)µ(dy) = −∫∂x∂y h(I)·γ(x)γ(y)dxdy = ∫[Ixy·log(I/(1−I)) + IxIy/(I(1−I))]·γ(x)γ(y)dxdy      (50)-(51)

Split into A1 (the Ixy·log(I) piece), A2 (the Ixy·log(1/(1−I)) piece, shown ≥0 directly as a sum-of-squares
via binomial expansion), and A3 (the IxIy/(I(1−I)) piece, split further into A31, A32, using the Schur
product theorem for PSD Hadamard products and Lemma 10 to bound error terms). After a long term-by-term
bookkeeping exercise (eqs. 52-73) the conclusion is A1+A2+A3 ≥ (1/8)Σ_{k≥0}(∫xᵏγ(x))² ≥ 0 for l small
enough (l below a threshold depending on p(·) alone), establishing concavity.

**Theorem 12** (the cardinality-reduction payoff — this is what licenses the 9-dim optimization). Fix p(·)
with p(1)=0, Π the Example-5 protocol with f(x)=l·x·p(x). Fix c, β, q, and optimize (43) over P0, P1 in
(45). For l>0 sufficiently small, the optimum is attained at (P0,P1) of the form

    P0 = a1δ_{b0} + a2δ_{b2} + a3δ_{b4}                                                                  (74)
    P1 = a1δ_{b1} + a2δ_{b3} + a3δ_{b5}                                                                  (75)

with b0,...,b5∈[0,1] and (a1,a2,a3) on the probability simplex — i.e. **each of P0, P1 needs only 3 atoms**,
and moreover the *same* three weights (a1,a2,a3) are shared between P0 and P1 (only the atom locations
differ). Proof: fix the two moment constraints q∫xP1+q̄∫xP0=1−c′ (76) and q∫f(x)P1+q̄∫f(x)P0=d (77) for
arbitrary c′∈[0,c], d∈[0,1]; by Lemma 11 the objective restricted to this affine slice is concave, so by
Krein–Milman the optimum is at an extreme point, which (for the unconstrained simplex of probability
measures) would be a single delta pair (δ_{b0}, δ_{b1}); adding the 2 linear constraints (76)-(77) means
extreme points of the constrained set are combinations of (at most) 3 delta-pairs (a codimension-2-in-atoms
argument, same style as the derivation of the two-atom optimum (7)-(8) for Sawin's problem). An alternative
argument is given too: for K≥4 atoms, use that Lemma 11's quadratic form has positive signature ≤1 on the
{mean=0}∩{first-moment-in-f=0} subspace, so a 2D polygon of mass-reweightings admits a direction along
which the objective is a concave quadratic, letting mass be moved to a boundary (reducing K) without
increasing the objective; iterate until K≤3.

## 6. Numerical evaluation (Section V) — the actual 0.382709 computation

Restrict attention to a specific basic instance of Example 5:

    f(x) = x·x̄ = x(1−x)             [this is *not* literally of the l·x·p(x) form with p(1)=0 and small l
                                       used to *prove* Lemma 11/Theorem 12 — Liu explicitly evaluates l=1,
                                       p(x)=x̄, i.e. pushes the perturbative regime to its boundary and
                                       verifies numerically that concavity/PSD still holds there; see below]

With x:=s̄, y:=t̄: **Π_{s,t}(0,0) = x·y·(1 + x̄·ȳ) = s̄t̄ + f(s̄)f(t̄) = s̄t̄(1+st)**.

### 6a. Section V-A: Positive-semidefiniteness (numerically verified hypothesis #1)

Two independent numerical checks that the quadratic form µ ↦ −∫h(Π_{s,r}(0,0))µ(ds)µ(dt) is PSD on the
codimension-2 subspace {∫dµ=0, ∫xµ(dx)=0} (needed for Theorem 12/Lemma 11 to apply at l=1):

1. **Direct eigenvalue computation.** Grid G on [0,1] with spacing 0.0004 (2499 points; MATLAB file
   `frankl3.m`, downloaded to `code/liu/frankl3.m`). Form the matrix M = [−h(Π_{s,t}(0,0))]_{s,t∈G}, project
   onto the codimension-2 subspace orthogonal to the constant and linear (and, per the code, also the f(x)
   moment) functions via an explicit projector P = I − A(AᵀA)⁻¹Aᵀ, symmetrize, and take the max eigenvalue
   of the projected matrix (they numerically minimize −h so check max eigenvalue ≤ 0, equivalently min
   eigenvalue of [−h(...)] restricted subspace ≥ 0... — the paper reports it as a **minimum eigenvalue**):
   *"The min eigenvalue is −2.3685×10⁻¹⁴, which is negligible considering the numerical errors for
   computation of large matrices. For comparison, the numerical precision of Matlab is 2.22×10⁻¹⁶; for the
   case of i.i.d. coupling where Π_{s,t}(0,0)=s̄t̄, the positive-semidefiniteness was rigorously shown in
   [AHS22], and the numerically evaluated minimum eigenvalue is −2.4206×10⁻¹⁴."* — i.e. the new coupling's
   numerical PSD-defect (−2.3685e-14) is *smaller in magnitude* than the pure-i.i.d. coupling's numerical
   defect (−2.4206e-14) even though the latter is a case that has been **rigorously proven** PSD. This is
   used as evidence the numerical error, not true negative-definiteness, explains the tiny negative
   eigenvalue for the new coupling too.

2. **Analytic power-series check.** With x=s̄, y=t̄, I:=Π_{s,t}(0,0)=xy(1+x̄ȳ), for µ with
   ∫µ(dx)=∫xµ(dx)=∫x²µ(dx)=0:

       −∫h(I)µ(dx)µ(dy) = ∫xy(1+x̄ȳ)·log((1−x+y−xy)/2)·µ(dx)µ(dy) + ∫(1−I)log(1−I)·µ(dx)µ(dy)          (78)

   (using ∫xy(1+x̄ȳ)log(2xy)µ(dx)µ(dy)=0 from the moment conditions). Expanding the integrand as
   Σ_{m,n} O_{mn} xᵐyⁿ, the PSD requirement becomes: [O_{mn}]_{m,n≥3} PSD (note: text says "m,n≥3" is used
   loosely; the operative statement given is "[O]_{2≤m,n≤L}"). Closed forms for the two log-coefficient
   families are given (eq. 79 for the log((1−x+y−xy)/2) part, eq. 80 for the log(1−I) part, both explicit
   finite combinatorial sums over binomial coefficients). Result: *"We numerically verified that
   [O]_{2≤m,n≤L} is positive semidefinite for L=29. For L≥30, the combinatorial numbers are not computed
   exactly (keeping only 15 digits), but we checked the numerical value of the minimum eigenvalue for up to
   L=90, all confirming the positive semidefinite hypothesis."* (MATLAB file `frankl7.m`, downloaded to
   `code/liu/frankl7.m`.)

**These two numerical checks (eigenvalue on a grid to L=29 exactly / L≤90 approximately) are exactly
Hypothesis #1 that Theorem 13 is conditioned on — they are NOT proven analytically for l=1 in this paper.**
The rigorous proof (Lemma 11) only covers "sufficiently small l" with an unspecified threshold; l=1 (the
value actually used for the headline 0.382709 constant) is outside the proven regime and relies entirely on
these numerical checks.

### 6b. Section V-B: the 9-dimensional optimization (this IS the exact optimization problem, transcribed in full)

Given the reduction of Theorem 12 (with l=1, f(x)=x·x̄), the optimization is over 9 real variables
**(a1, a2, q, b0, b1, b2, b3, b4, b5)**, all with b0,b2,b4 paired to P0 (weights a1,a2,a3=1−a1−a2) and
b1,b3,b5 paired to P1 (same weights). Write X̄,Ȳ for 1−X,1−Y where needed (standard bar notation), and let
q̄:=1−q.

**Minimize** (over the 9 variables):

    [ β̄·E_{(q̄P0+qP1)^⊗2}[h(XY)]  +  β·E_{q̄P0^⊗2 + qP1^⊗2}[h(XY + XY·X̄Ȳ)] ]  /  E_{q̄P0+qP1}[h(X)]      (81)

**Subject to:**

    q̄(a1·b0 + a2·b2 + a3·b4) + q(a1·b1 + a2·b3 + a3·b5) ≥ 1 − c                                          (82)
    0 ≤ a1, a2, q, b0, b1, ..., b5 ≤ 1                                                                    (83)
    a1 + a2 ≤ 1     [so a3 := 1−a1−a2 ≥ 0]                                                                (84)

**Reading of the notation (important, resolved by cross-checking Liu's own MATLAB code `frankl5.m`, since
the paper's prose is terse here):** X, Y in (81) denote the raw atoms of the mixture-of-two-iid
distribution — i.e., X,Y are literally S̄, T̄ values (the bar of S,T; recall Section V uses the x:=s̄
convention throughout) — NOT the underlying probability parameters s,t themselves. The b_i are therefore
values of S̄ (this is why constraint (82), a lower bound on a weighted average of the b_i, corresponds to
an *upper* bound 1−c on... i.e. **E[S] ≤ c** exactly as required by the c-parametrized family (43): since
E[S̄]=Σweights·b_i ≥ 1−c ⟺ E[S] ≤ c). The first numerator term E_{(q̄P0+qP1)^⊗2}[h(XY)] is Gilmer's plain
i.i.d. term E[h(S̄T̄)] with S,T drawn *independently* from the full mixture q̄P0+qP1 (not locked to the same
branch). The second numerator term, E_{q̄P0^⊗2+qP1^⊗2}[h(XY+XYX̄Ȳ)], is the conditionally-IID term
E[h(Π_{S,R2}(0,0))] specialized to f(x)=x·x̄: writing Π(0,0)=xy(1+x̄ȳ)=xy+xy·x̄ȳ=XY+XY·X̄Ȳ, and averaging
over S,R2 drawn as a matched pair from the *same* branch (both from P0 with prob q̄, or both from P1 with
prob q) — i.e. this is E_{q̄P0⊗P0 + qP1⊗P1}[h(Π(0,0))], written in the paper as q̄P0^⊗2+qP1^⊗2. The
denominator is the plain entropy of the S̄-marginal of the mixture.

**Optimization method (verbatim):** *"We used various algorithms (interior-point, sqp, active-set) from
Matlab optimization package to solve constrained optimization with about 10⁵ different random
initializations (code can be found in https://jingbol.web.illinois.edu/frankl5.m)."* — downloaded to
`code/liu/frankl5.m`. Certification logic: c is a valid lower bound if, for *some* β∈(0,1), the optimal
value of (81) subject to (82)-(84) is **≥ 1**.

**Result (verbatim quote):** *"The percentage of different local optimizers found changes with the choice
of solvers. One common local minimum found was simply a one-point mass, but the best local minimum found,
which we conjecture to be global, is the following (up to symmetries):"*

    q = 0                                                                                                (85)
    P0 = p*·δ_{x*} + p̄*·δ_0                                                                              (86)

i.e. the found optimum collapses to **q=0** (all mass in the P0 branch — P1/b1,b3,b5/a3-weighted parts
irrelevant) and P0 itself collapses to only **2 of its 3 allowed atoms** (one atom at x*, the rest of the
mass p̄*=1−p* at 0; effectively a3=0 or two atoms coincide at 0). p*, x* solve:

    x*² + x*²(1+x̄*²) = 1                                                                                 (87)
    p*²·h(x*²) − p*·h(x*) = 0                                                                             (88)

Define **c′ := 1 − p*·x***. The optimal β should satisfy [see §7 below for a flagged transcription issue]:

    d(β̄·p²h(x²) + β·h(p²(1+p̄²)) − p·h(x)) |_{p=p*, x=x*} = 0                                            (89)
    d(p·x) |_{p=p*, x=x*} = 0                                                                              (90)

*"...where the differentials are in x and p, and we can solve dp/dx and β from the two equations to obtain
expression of the optimal β* in terms of x* and p* (omitted here)."* — **the closed form for β* is never
written out in the paper**, only the final decimal value is given.

**Reported numerical values (verbatim):**

    p* ≈ 0.893604513905457                                                                               (91)
    x* ≈ 0.690787593924988                                                                                (92)
    c′ ≈ 0.382709087918741                                                                                (93)
    β* ≈ 0.100052559862974                                                                                (94)

**Theorem 13** (verbatim): *"Under the positive-semidefiniteness hypothesis in Section V-A and the
hypothesis of the global minimizer structure in Section V-B, the constant in the union-closed sets
conjecture can be improved to c′ in (93)."*

**Both hypotheses named in Theorem 13 are explicitly non-rigorous:**
1. The PSD hypothesis (§6a) — verified only on a finite grid / finite polynomial-degree truncation (L up to
   29 exact, up to 90 with reduced numerical precision), for the specific l=1 case, outside the range where
   Lemma 11's proof (small l) formally applies.
2. The "global minimizer structure" hypothesis (§6b) — the claim that the *global* optimum of the 9-dim
   problem has the specific 2-atom, q=0 form (85)-(86), rather than genuinely using all 9 dimensions, is
   based on ~10⁵ random restarts finding this as the *best local* optimum, explicitly flagged by Liu as
   "conjecture to be global" — **not a global-optimality proof** (e.g. no branch-and-bound, no
   interval-arithmetic certificate, no convexity argument for global optimality of this specific point).

## 7. Flagged ambiguity / likely typo (per task instructions — documenting rather than silently guessing)

Equation (89) as printed (confirmed by direct visual inspection of the PDF page image, not a text-extraction
artifact) reads:

    d(β̄·p²h(x²) + β·h(p²(1+p̄²)) − p·h(x)) |_{p=p*,x=x*} = 0

The middle term `h(p²(1+p̄²))` has **p** as the argument of the inner `(1+·̄²)` expression and as the sole
argument of the outer h(·) (no leading p² multiplying it). This is inconsistent with:
(a) the general objective (81), where the analogous term (specialized to the 2-atom q=0, single-nonzero-atom
    structure of (85)-(86)) should be `p²·h(x²(1+x̄²))` — i.e. probability weight p² multiplying h(·) applied
    to the point-value expression x²(1+x̄²), matching the E_{P0^⊗2}[h(XY+XYX̄Ȳ)] term evaluated at the
    two-point distribution P0=p*δ_{x*}+p̄*δ_0 (only the both-atoms-at-x* branch, probability p², contributes
    since the other branches give X̄Ȳ-type expressions evaluating with X or Y at 0);
(b) Liu's own `frankl5.m` code, which computes the analogous `ehpi`/`pi0` quantities strictly as functions of
    the atom-location variables (the b's), never substituting a probability weight into h(·)'s argument.

My working hypothesis is that the correct expression is `β·p²·h(x²(1+x̄²))`, i.e. a `p↔x` swap plus a missing
`p²` prefactor, most likely introduced by a LaTeX macro-substitution slip while adapting the earlier
general-β equations (12)-(15) template to this section. I could not access a second independently-typeset
source (no published v2, no journal typeset version located) to cross-check against, so this cannot be fully
confirmed — it is presented here as a flagged discrepancy, not a silent correction. Critically, **equation
(89)-(90) are not used computationally anywhere else in the paper** — Liu states the closed-form solution for
β* is "omitted," and the paper's own numerical pipeline (`frankl5.m`) solves the full 9-dimensional
optimization directly rather than through (89)-(90) — so this typo (if it is one) does not appear to
propagate into the reported numbers (91)-(94), which come from the independent MATLAB multi-start
optimization plus equations (87)-(88) (which are self-consistent and were confirmed to reproduce (91)-(92)
in my reproduction, see `code/liu_reproduce.py`).

## 8. Extending the coupling class / conjectured ceiling

- **Markov chains of auxiliary variables**: not discussed anywhere in the paper. The conditionally-IID
  class already uses a single auxiliary variable U (or Uⁱ sequence); there is no discussion of chaining
  multiple auxiliary variables, hierarchical mixtures, or other generalizations of Definition 2.
- **Maximal-correlation (Yu's) class**: explicitly checked and ruled out as a source of further improvement
  via the same small-perturbation technique (Remark 1, §4 above) — the relevant inequality (42) was verified
  to be negative for all ρ∈(0,1), i.e. no ρ gives a Lemma-8-style strict gain over c*.
- **No explicit numeric "ceiling" is conjectured for the conditionally-IID class itself.** Liu does not
  state a belief that 0.382709 (or any nearby number) is the best this coupling class can do; the paper
  frames c′≈0.382709 purely as "the best local minimum found" in a specific 9-dim reduction of a specific
  basic instance (f(x)=x·x̄) of Example 5, and does not discuss whether other choices of f(·) (or larger l,
  or higher-cardinality mixtures beyond Theorem 12's 3-atom reduction, which itself is only proven optimal
  for "sufficiently small l") could do better. This is left open.
- The paper title's "basic instance" framing (Abstract: *"For a basic instance from this class..."*) and
  the explicit statement that Theorem 12's cardinality reduction is proven only for small l while the
  numerics use l=1 both suggest Liu views this as a first/minimal demonstration of the conditionally-IID
  class rather than an exhaustive optimization over it — but no explicit statement to that effect, nor any
  conjectured limiting/ceiling constant, appears in the text.
