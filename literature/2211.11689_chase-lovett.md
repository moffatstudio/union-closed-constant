## (a) Abstract and main theorem statements, exact

**Abstract.** "A set system is called union closed if for any two sets in the set system their union is also in the set system. Gilmer recently proved that in any union closed set system some element belongs to at least a $0.01$ fraction of sets, and conjectured that his technique can be pushed to the constant $\frac{3-\sqrt5}{2}$. We verify his conjecture; show that it extends to approximate union closed set systems, where for nearly all pairs of sets their union belong to the set system; and show that for such set systems this bound is optimal."

**Definition 1.1 (Union closed set system).** $\mathcal{F}$ is union closed if for all $A,B\in\mathcal{F}$, $A\cup B\in\mathcal{F}$.

**Definition 1.2 (Approximate union closed set system).** Let $0\le c\le1$. $\mathcal{F}$ is **$c$-approximate union closed** if for at least a $c$-fraction of the pairs $A,B\in\mathcal{F}$ (i.e. $c$-fraction of $\mathcal{F}\times\mathcal{F}$) we have $A\cup B\in\mathcal{F}$. Informally, $\mathcal{F}$ is *approximate union closed* if it is $(1-o(1))$-approximate union closed.

Let $\psi:=\frac{3-\sqrt5}{2}\approx0.38$.

**Theorem 1.3.** Let $\mathcal{F}$ be a $(1-\varepsilon)$-approximate union closed set system, where $\varepsilon<1/2$. Then there is an element which is contained in a $\psi-\delta$ fraction of sets in $\mathcal{F}$, where
$$\delta = 2\varepsilon\left(1+\frac{\log(1/\varepsilon)}{\log|\mathcal{F}|}\right).$$

**Example 1.4 (optimality/sharpness for the approximate version — see part (c) below).**

## (b) Complete proof transcription

### Section 2 — Preliminaries

All logarithms base 2. $h(x)=-(x\log x+(1-x)\log(1-x))$ (binary entropy). Let $\varphi=1-\psi=\frac{\sqrt5-1}{2}$, the positive root of $x^2+x-1=0$.

**Claim 2.1** (used as an input, verified by computer simulation in this paper, "proven rigorously in [AHS]"). The minimum of $\dfrac{h(x^2)}{xh(x)}$ for $x\in[0,1]$ is attained at $x=\varphi$.

### Section 3 — Analytic claims

Define $f:[0,1]^2\to\mathbb{R}_{\ge0}$,
$$f(x,y):=\frac{h(xy)}{h(x)y+h(y)x}\quad\text{for }(x,y)\in(0,1)^2,$$
extended continuously by $f(x,y)=1$ if $x\in\{0,1\}$ or $y\in\{0,1\}$.

**Claim 3.1.** $f$ is minimized at $(\varphi,\varphi)$, where $f(\varphi,\varphi)=\dfrac{1}{2\varphi}$.

*Proof.* By routine calculation, $f$ is continuous on $[0,1]^2$ and $f(x,y)<1$ on $(0,1)^2$, so the minimum is interior. Let $g(x)=h(x)/x$ on $(0,1)$; then $f(x,y)=\dfrac{g(xy)}{g(x)+g(y)}$.

*Step 1: minimizer lies on the diagonal.* Suppose $f$ is minimized at $(x^*,y^*)$, $\alpha=f(x^*,y^*)$. Define $F(x,y)=g(xy)-\alpha(g(x)+g(y))$. Then $F\ge0$ everywhere on $(0,1)^2$ and $F(x^*,y^*)=0$, so the partial derivatives vanish there:
$$\frac{\partial F}{\partial x}(x^*,y^*)=\frac{\partial F}{\partial y}(x^*,y^*)=0.$$
Compute $\frac{\partial F}{\partial x}(x,y)=g'(xy)\cdot y-\alpha g'(x)$, $\frac{\partial F}{\partial y}(x,y)=g'(xy)\cdot x-\alpha g'(y)$. Define $G(x)=xg'(x)$; the two vanishing conditions give $G(x^*)=G(y^*)$. Direct calculation: $g'(x)=\dfrac{\log(1-x)}{x^2}$ (natural consequence of differentiating $h(x)/x$), which implies $G$ is **monotonically decreasing**, forcing $x^*=y^*$.

*Step 2: reduce to Claim 2.1.* Restricting to $x=y$: $f(x,x)=\dfrac{h(x^2)}{2xh(x)}$. By Claim 2.1 this is minimized at $x=\varphi$. Since $\varphi^2=1-\varphi$, $h(\varphi^2)=h(\varphi)$, so
$$f(\varphi,\varphi)=\frac{1}{2\varphi}. \blacksquare$$

**Corollary 3.2.** For $x,y\in[0,1]$:
$$h(xy)\ \ge\ \frac{1}{2\varphi}\big(xh(y)+yh(x)\big).$$
(Immediate from Claim 3.1's minimum value applied to the definition of $f$.)

### Section 4 — Proof of the main theorem

**Claim 4.1.** Let $A,B$ be independent random variables in $\{0,1\}^n$. Assume for all $i\in[n]$, $\Pr[A_i=0]\ge p$ and $\Pr[B_i=0]\ge p$. Then
$$H(A\cup B)\ \ge\ \frac{p}{2\varphi}\big(H(A)+H(B)\big).$$

*Proof.* By chain rule and data-processing inequality (conditioning on more information cannot decrease entropy of a function of it — here $(A\cup B)_{<i}$ is a function of $A_{<i},B_{<i}$):
$$H(A\cup B)=\sum_{i\in[n]}H(A_i\cup B_i\mid(A\cup B)_{<i})\ \ge\ \sum_{i\in[n]}H(A_i\cup B_i\mid A_{<i},B_{<i}).$$
Let $p(x)=\Pr[A_i=0\mid A_{<i}=x]$, $q(y)=\Pr[B_i=0\mid B_{<i}=y]$. By Corollary 3.2 applied pointwise,
$$H(A_i\cup B_i\mid A_{<i}=x,B_{<i}=y)=h\big(p(x)q(y)\big)\ge\frac{1}{2\varphi}\big(p(x)h(q(y))+q(y)h(p(x))\big)$$
(note: $\Pr[A_i\cup B_i=0\mid A_{<i}=x,B_{<i}=y]=\Pr[A_i=0]\Pr[B_i=0]=p(x)q(y)$ by independence). Averaging over the independent $A_{<i},B_{<i}$:
$$H(A_i\cup B_i\mid A_{<i},B_{<i})\ge\frac{1}{2\varphi}\Big(\mathbb{E}_{A_{<i}}[p(A_{<i})]\cdot\mathbb{E}_{B_{<i}}[h(q(B_{<i}))]+\mathbb{E}_{B_{<i}}[q(B_{<i})]\cdot\mathbb{E}_{A_{<i}}[h(p(A_{<i}))]\Big)$$
$$=\frac{1}{2\varphi}\Big(\Pr[A_i=0]\cdot H(B_i\mid B_{<i})+\Pr[B_i=0]\cdot H(A_i\mid A_{<i})\Big).$$
Using $\Pr[A_i=0]\ge p$, $\Pr[B_i=0]\ge p$:
$$H(A_i\cup B_i)\ge\frac{p}{2\varphi}\big(H(A_i\mid A_{<i})+H(B_i\mid B_{<i})\big).$$
Sum over $i\in[n]$. $\blacksquare$

**Proof of Theorem 1.3.** Let $\mathcal{F}$ be $(1-\varepsilon)$-approximate union closed over $[n]$. Let $p=\min_{i\in[n]}\Pr_{A\in\mathcal{F}}[A_i=0]$ (goal: lower-bound $1-p$, the max element-frequency). Let $A,B\in\mathcal{F}$ uniform, independent. By Claim 4.1,
$$H(A\cup B)\ \ge\ \frac{p}{2\varphi}\big(H(A)+H(B)\big)=\frac{p}{\varphi}\log|\mathcal{F}|.$$
**Upper bound on $H(A\cup B)$:** let $I=\mathbb{1}[A\cup B\in\mathcal{F}]$; by hypothesis $\Pr[I=1]\ge1-\varepsilon$. Then
$$H(A\cup B)\le H(A\cup B,I)=H(I)+H(A\cup B\mid I{=}0)\Pr[I{=}0]+H(A\cup B\mid I{=}1)\Pr[I{=}1].$$
Bound term by term:
- $\Pr[I=0]\le\varepsilon<1/2 \Rightarrow H(I)\le h(\varepsilon)\le2\varepsilon\log(1/\varepsilon)$.
- When $I=0$: naive bound $H(A\cup B\mid I{=}0)\le H(A,B\mid I{=}0)\le2\log|\mathcal{F}|$.
- When $I=1$: $A\cup B\mid I{=}1$ is supported on $\mathcal{F}$, so $H(A\cup B\mid I{=}1)\le\log|\mathcal{F}|$.

Combining:
$$\frac{p}{\varphi}\log|\mathcal{F}|\ \le\ H(A\cup B)\ \le\ 2\varepsilon\log(1/\varepsilon)+(1+2\varepsilon)\log|\mathcal{F}|.$$
Rearranging:
$$1-p\ \ge\ 1-\varphi-2\varepsilon\left(1+\frac{\log(1/\varepsilon)}{\log|\mathcal{F}|}\right).$$
Since $1-\varphi=\frac{3-\sqrt5}{2}=\psi$, this is exactly the claim with $\delta=2\varepsilon\left(1+\frac{\log(1/\varepsilon)}{\log|\mathcal{F}|}\right)$. $\blacksquare$

## (c) Tightness / extremal case — Example 1.4 (the explicit optimality construction)

**Construction, verbatim in content.** Let $n$ be large. Define, over $[n]$:
$$\mathcal{F}_1=\{x\in\{0,1\}^n : |x|=\psi n+n^{2/3}\},\qquad \mathcal{F}_2=\{x\in\{0,1\}^n : |x|\ge(1-\psi)n\},\qquad \mathcal{F}=\mathcal{F}_1\cup\mathcal{F}_2.$$
That is, $\mathcal{F}_1$ is the single "layer" of the Boolean cube at Hamming weight exactly $\psi n+n^{2/3}$ (a slice just above $\psi n$), and $\mathcal{F}_2$ is the "upper half" of the cube: all strings of weight at least $(1-\psi)n$.

The paper states, verbatim: "One can verify that: (i) $\mathcal{F}$ is $1-o(1)$ approximate union closed (using the fact that $1-\psi=2\psi-\psi^2$); (ii) that $|\mathcal{F}_2|=o(|\mathcal{F}_1|)$; and (iii) that hence each element $i\in[n]$ is in at most $\psi+o(1)$ fraction of sets in $\mathcal{F}$." The paper does **not** spell out the verification in more detail than this — it asserts (i)-(iii) as directly checkable. The identity $1-\psi=2\psi-\psi^2$ is exactly the golden-ratio fixed-point relation (both sides equal $\varphi$ under the substitution $\psi=1-\varphi$, since $2\psi-\psi^2 = 1-(1-\psi)^2 = 1-\varphi^2 = 1-(1-\varphi)=\varphi=1-\psi$), which is why the two-layer construction self-closes approximately: the "typical" union-weight of two elements of $\mathcal{F}_1$ (weight $\approx\psi n$ each) concentrates near $(2\psi-\psi^2)n=(1-\psi)n$, matching the threshold defining $\mathcal{F}_2$.

*Below this line is this transcriber's own elaboration, not paper text, offered only as plausibility reasoning for (i)-(iii); treat with lower confidence than the boxed quote above.* Two independent uniformly-chosen weight-$(\psi n+n^{2/3})$ vectors have union-weight concentrated (by standard concentration for the weight of a union of two random sets of fixed size) around its mean $(2\psi-\psi^2)n$ with fluctuations of order $\sqrt n \ll n^{2/3}$, so with probability $1-o(1)$ the union has weight $\ge(1-\psi)n$ and lands in $\mathcal{F}_2\subset\mathcal{F}$ — this is presumably the mechanism behind (i). For (ii), $\mathcal{F}_1$ is a single binomial-coefficient-sized layer near relative weight $\psi\approx0.382$ while $\mathcal{F}_2$ is the sum of all layers of relative weight $\ge1-\psi\approx0.618$; since $\binom{n}{\alpha n}$ decays away from $\alpha=1/2$ and $1-\psi$ is farther from $1/2$ than $\psi$ is on the same side... [this last comparison is not immediate; readers should treat (ii) as an asserted, not independently re-derived, fact].

**Conclusion:** this shows the threshold $\psi=\frac{3-\sqrt5}{2}$ is **optimal for approximate union-closed set systems** — no bound better than $\psi+o(1)$ can hold in the approximate setting, matching Theorem 1.3 as $\varepsilon\to0$.

**Why this construction crucially needs only *approximate*, not exact, union-closure (transcriber's analysis — not explicit in the paper, which does not discuss this point):** $\mathcal{F}$ as built is **not exactly union-closed** — a $o(1)$-fraction of pairs $A,B\in\mathcal{F}_1$ union to a set of weight *not* landing exactly in $\mathcal{F}_2$ (concentration is not perfect; the slice-plus-tail structure only approximately absorbs unions). The construction exploits precisely this slack: it needs the union of two typical elements to land in $\mathcal{F}$ only with probability $1-o(1)$, not probability $1$. For an *exactly* union-closed family, $\mathcal{F}_1\cup\mathcal{F}_2$ as literally defined would generally fail closure (some unions of two weight-$(\psi n+n^{2/3})$ sets miss the exact threshold $(1-\psi)n$ or land at an intermediate weight outside both $\mathcal{F}_1$ and $\mathcal{F}_2$), so this specific extremal example is **not available** to a hypothetical exact-conjecture counterexample-seeker — it only witnesses tightness of Theorem 1.3's approximate statement. This is exactly the gap the exact conjecture (asking for constant $1/2$) would need to exploit: the entropy method's core inequality (Corollary 3.2 / Claim 4.1) is a *pointwise*, per-coordinate statement that never uses exact closure at all (only $\Pr[A_i=0]\ge p$, a marginal condition) — exact closure is used *only* in the upper bound $H(A\cup B\mid I=1)\le\log|\mathcal{F}|$ becoming exact ($\varepsilon=0$: $H(A\cup B)\le\log|\mathcal{F}|$ outright, no error terms), not in strengthening the lower bound on $H(A\cup B)$ itself. Hence the entropy method's ceiling at $\psi$ is a property of the *lower bound side* (Claim 4.1/Corollary 3.2), which is oblivious to whether closure is exact or approximate — this is exactly why Example 1.4's approximately-closed family can already saturate it.

## (d) Remarks on limits of the method / open questions

- The paper states its result as *verifying Gilmer's conjectured value* $\psi=\frac{3-\sqrt5}{2}$ for the exact conjecture, and *separately* shows this value is the best possible for the **approximate** version — i.e., the paper itself identifies the entropy method (via Claim 4.1) as being agnostic to exact vs. approximate closure, which is the reason $\psi$ is a hard ceiling for this proof technique regardless of which version of the conjecture is being attacked.
- No sketch is given here (as in Sawin) for surpassing $\psi$; the paper's contribution is establishing $\psi$ exactly (matching Gilmer's conjectured value) and proving its optimality in the approximate regime, not proposing routes beyond it.
